# Simple Flask Application

A minimal Python web application built with the Flask framework that displays a "Hello world" message.

## Prerequisites

- Python 3.8 or higher
- pip (Python package installer)

## Installation

1. Clone or download this repository to your local machine.
2. Open your terminal and navigate to the project directory.
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Application

1. Save your application code in a file named `app.py`.
2. Run the Flask development server:
   ```bash
   flask run
   ```
3. Open your web browser and navigate to `http://127.0.0`.

## Project Structure

- `app.py`: The main application script containing the server logic and routes.
- `requirements.txt`: List of Python packages required to run the application.
